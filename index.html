【原立刷App用户快捷注册】位于【微信注册/登录】按钮下方，文字后带右箭头「›」；点击进入「快捷注册－账号验证」页
未勾选协议时点击入口弹出协议确认弹窗，与【微信注册/登录】现有弹窗相同；【同意并继续】自动勾选并进入账号验证页，【取消】关闭弹窗停留本页
协议勾选行由【微信注册/登录】按钮下方移到页面底部「网站支持 IPv6」上方

调整内容说明
【原立刷App用户快捷注册】位于页面最下方【完成注册】按钮与「已有账户，立即登录」之间，随页面滚动；点击进入「快捷注册－账号验证」页

合伙人App存量用户快捷进件：身份证号由后6位改为后4位

嘉联合伙人App → 首页 → 立刷进件 →【存量用户快捷进件】

调整内容说明
身份证号（原账户类型「立刷App」）输入框提示由「请输入身份证号后6位」改为「请输入身份证号后4位」；手机号与后4位同时匹配才通过，其它判定、提示与后续流程不变
原账户类型「立刷电签」不改，仍输入完整身份证号

快捷注册－账号验证（新增页）

登录页或注册页【原立刷App用户快捷注册】→ 本页

项说明
输入项1、原立刷App注册手机号
2、身份证号后4位（合伙人App仍为后6位，不改）
【下一步】判定1、手机号不存在 → 提示「账号不存在」，可返回注册页
2、手机号存在、后4位不符 → 提示「身份证验证有误」
3、该身份证已注册电签 → 与合伙人App现有逻辑相同
4、通过且有原立刷资料 → 身份信息确认页
5、通过但无原立刷资料 → 提示「未查到原立刷app资料，请用其他方式注册」，停留本页
数据范围未同步到当前系统的原立刷商户也要能查到并走快捷注册

快捷注册－身份信息确认（新增页）

账号验证通过 → 本页

项说明
身份证照片不反显原图，人像面／国徽面都用占位图；可点击重新上传
姓名、身份证号脱敏展示
身份证有效期已过期 → 顶部提示并要求重新上传身份证，未重新上传不能进入下一步

快捷注册－入网信息确认（新增页）

身份信息确认【下一步】→ 本页 →【确认继续】→ 门店认证（与原有逻辑相同）

项说明
结算卡照片1、不反显原图，用占位图
2、原立刷结算卡照片重新识别一次：不通过 → 照片下红字提示，商户重新上传
3、系统中没有结算卡照片 → 不反显卡号，商户上传后识别
开户名称、结算卡号脱敏展示
入网地址按当前定位展示，可修改，与原有选点逻辑相同
后续认证原立刷做过人脸的，意愿确认与人脸整步跳过；原立刷有信用卡记录的，信用卡认证跳过
